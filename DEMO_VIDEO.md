## 🏗️ SCENE 2: The Architecture (0:20 - 0:50)

**[Screen: Show architecture diagram or animated flow]**

**Voiceover:**
> "RareNet uses a Two-Tier Privacy Architecture."

**[Show Tier 1 - CyborgDB]**
> "Tier 1: CyborgDB encrypts all patient data at-rest, in-transit, and in-use. Even if the database is breached, attackers see only random noise."

**[Show Tier 2 - Privacy Firewall]**
> "Tier 2: Our Privacy Firewall enforces K-Anonymity. If a query matches fewer than 5 patients globally, the system blocks the result to prevent re-identification."

**[Text on screen: "Two-Tier Privacy = Storage Security + Access Privacy"]**

## 📋 Recording Checklist

### Before Recording:
- [ ] Run `.\run_seeding.ps1` with 'y' to ensure fresh data
- [ ] Verify frontend is running on http://localhost:5173
- [ ] Login to the app (use Mumbai hospital credentials)
- [ ] Test both demo queries (Ehlers-Danlos ✅ and Ghost Case 🛑)
- [ ] Confirm Ghost Case gets BLOCKED

### During Recording:
- [ ] Record in 1080p (minimum 720p)
- [ ] Use clear audio (external mic recommended)
- [ ] Show your face in corner (builds trust with judges)
- [ ] Speak slowly and clearly
- [ ] Pause between scenes for editing

### Screen Recording Setup:
- [ ] Close unnecessary tabs/windows
- [ ] Hide desktop icons if recording desktop
- [ ] Use full-screen browser for app demo
- [ ] Enable "Do Not Disturb" mode

### Post-Production:
- [ ] Add captions for key points
- [ ] Add background music (subtle, professional)
- [ ] Add transitions between scenes
- [ ] Export in MP4 format
- [ ] Keep under 3 minutes
